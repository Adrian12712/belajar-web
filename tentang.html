🎯 Tujuan dan Sasaran Pengguna Website

Jaga Pesisir dikembangkan sebagai platform edukasi interaktif berbasis web untuk mendukung pencapaian Tujuan Pembangunan Berkelanjutan (SDG), khususnya SDG 13 (Climate Action) dan SDG 14 (Life Below Water) di Indonesia.

Sasaran Pengguna:

  • Pelajar & Remaja: Meningkatkan kesadaran dini mengenai ancaman sampah plastik dan pentingnya ekosistem pesisir melalui kuis interaktif serta aksi harian.
  • Masyarakat Umum: Memberikan pemahaman komprehensif terkait peran penting mangrove dan terumbu karang bagi mitigasi perubahan iklim.
  • Pendidik: Sebagai media referensi pendukung pembelajaran lingkungan hidup di sekolah.

💻 Catatan Teknologi

Website ini dibangun murni menggunakan teknologi web standar tanpa ketergantungan framework eksternal:

  • HTML5: Struktur semantik dokumen web (<header>, <main>, <section>, <footer>).
  • CSS3: Desain visual modern menggunakan CSS Variables, Flexbox, dan CSS Grid.
  • Media Queries: Memastikan tata letak responsif secara sempurna di berbagai ukuran layar (Desktop, Tablet, Smartphone).
  • GitHub Pages: Platform deployment publik untuk aksesibilitas online tanpa login.
